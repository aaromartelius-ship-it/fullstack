sequenceDiagram
    participant browser
    participant server

    Note right of browser: Käyttäjä kirjoittaa tekstikenttään ja painaa "Tallenna" (Save)

    Note right of browser: spa.js estää oletustoiminnon (e.preventDefault()), lisää muistiinpanon listaan ja piirtää sen heti näytölle (DOM)

    browser->>server: POST [https://studies.cs.helsinki.fi/exampleapp/new_note_spa](https://studies.cs.helsinki.fi/exampleapp/new_note_spa)
    activate server
    Note over browser,server: Pyynnön Content-Type on application/json, ja body sisältää uuden muistiinpanon JSON-muodossa
    Note left of server: Palvelin vastaanottaa JSON-datan ja lisää sen muistiinpanolistaan
    server-->>browser: HTTP 201 Created ({"message":"note created"})
    deactivate server

    Note right of browser: Selain vastaanottaa vahvistuksen; sivua ei uudelleenohjata eikä ladata alusta
